# skyblock-translation-data

Mirrored translation JSON tables for the [skyblock-translation](https://github.com/ShoeBox-CX/SkyblockTranslator) Fabric mod, fetched by its cloud-sync feature (`/sbtranslate reload` / `/sbtranslate cloud update`).

`manifest.json` lists each file's SHA-256 and byte size; the mod verifies both before installing anything. This repo is kept in sync automatically by a GitHub Action in the (private) source repo — do not edit files here by hand, they will be overwritten on the next push.
